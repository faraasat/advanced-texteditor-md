Source pane

The Markdown view (and the left half of split) gets syntax tinting, line numbers that follow wrapped lines, a soft-wrap toggle, a current-line band, bracket and emphasis pairing, Tab / Shift+Tab to indent, Alt+ArrowUp / Alt+ArrowDown to move lines and Mod-D to duplicate them. The stored Markdown is exactly the textarea's text. Press Escape, then Tab, to leave the pane. URL parameters: value, mode (markdown, split, wysiwyg), readonly=1, wrap=0, numbers=0, tint=0, dir=rtl, theme=dark.
