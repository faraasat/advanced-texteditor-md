Comments

Select text and press Mod-Alt-M (or the toolbar button) to comment on it. The document stores only [anchored text](comment:ID); the threads live in this page (the host). Alt-F9 and Shift-Alt-F9 move between comments. URL parameters: value, readonly=1, layout (document shows the margin markers), dir=rtl, theme=dark.
