Present

The same Markdown as slides. → Space Enter go on, ← goes back (reversed in right-to-left text), Home/End jump, a number then Enter goes to that slide, F toggles fullscreen and S the speaker view with notes and a timer. Swipe or click the edges on a touch screen. URL parameters: split (rule, h1, h2, auto), presenter=1, hash=1, theme (light, dark), dir=rtl, nofs=1 (no Fullscreen API), start.

An editor with the Present command

The toolbar button (or the command palette, Ctrl+Shift+P) opens the current text full-window. Esc closes it and puts the cursor back.
